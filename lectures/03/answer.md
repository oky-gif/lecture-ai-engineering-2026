# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：素のLLMは講座固有の情報を参照せず、「基礎・応用・発展」という一般的な内容を推測して回答した。一方、エージェントは用語集を検索し、講座で定められた「基礎・実装・発展」を正しく回答した。
- `--trace` で見えたツール呼び出し（ツール名と引数）：search_glossary({'query': '3レベル'})。追加ツールの確認では search_glossary({'query': 'LoRA'}) と make_quiz({'topic': 'LoRA'}) が呼び出された。
- 1つの質問での LLM 呼び出し回数（`requests`）：3レベルについての質問では2回、LoRAのクイズ作成では3回だった。
- 追加したツールと、docstring に書いた説明：make_quiz(topic: str) を追加した。指定されたAI関連のテーマについて理解度確認クイズを作成するためのツールで、ユーザーがクイズや練習問題を求めたときに使用することをdocstringに記載した。

## 宿題

- 取り組んだレベル：基礎
- やったこと：app/tools.py の search_glossary のdocstringを変更した。変更前は用語について回答する前に検索するよう指示していたが、変更後は一般的なAI用語についてモデル自身の知識で回答できる場合、検索を必須としない説明にした。INSTRUCTIONS は変更せず、同じ質問「LoRAとは何ですか？」を --trace 付きで実行して比較した。
- 結果：変更前後ともに search_glossary が1回呼び出され、検索キーワードは「LoRA」であった。LLMへのリクエスト回数も2回で変化はなかった。一方、出力トークン数は143から205に増加し、回答内容にも違いが見られた。
- 気づき・疑問：ツールの説明文を変更しても、検索回数は変化しなかった。これは INSTRUCTIONS に「必ず検索する」という指示が残っていたため、その影響が強かった可能性があると考えた。AIの動作はツールの説明文だけでなく、エージェント全体への指示にも左右されると考えられる。
